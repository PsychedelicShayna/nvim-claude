## Sol 6.1 medium benchmark candidate, 2026-10-21

- Add the lazy.nvim entry point, configurable native mappings, prompt and answer floats, safe tracked selection replacement and cursor insertion.
- Add a lazy Python SDK bridge with framed stdio JSON-RPC, streaming, interruption, asynchronous isolated provisioning and official CLI login.
- Add runtime model/effort discovery, manual selectors, physical-context planning, actual runtime compaction, snapshots/diffs, saved conversations, sticky mode and exact owned-session cleanup.
- Add presentation-only punctuation normalization and session-local system-prompt editing with exact session resumption.
- Refuse unsupported hard input ceilings, including the default 100k, before model dispatch. Model-default operation requires an explicit user choice. Record this strict-budget acceptance gap rather than presenting an overhead allowance as a verified billing guarantee.
